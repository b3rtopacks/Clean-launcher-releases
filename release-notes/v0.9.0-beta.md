# Clean Launcher — Public Beta v0.9.0

**A calm, ad-free home screen for Fire TV. Free. Early public beta.**

**Install:** in the Downloader app on your Fire TV, enter `https://github.com/b3rtopacks/clean-launcher-releases/releases/latest/download/CleanLauncher.apk`
or download `CleanLauncher-0.9.0-beta.apk` below. `CleanLauncher.apk` is the same file under a fixed
name, used by that permanent address.
Full step-by-step instructions are in the [README](https://github.com/b3rtopacks/clean-launcher-releases#install).

> This is an early beta, not a finished launcher for every Fire TV. It has been tested on one
> device: **Fire TV Stick 4K (2nd Gen, 2023) running Fire OS 8.1.8.5**. Other Fire TV models and
> software versions are unverified. Clean Launcher is independent and not affiliated with Amazon.

## The Clean Launcher experience
- A simple grid of your installed apps, with no adverts, sponsored rows, recommendations or tracking.
  The app has no internet permission.
- Real app icons, shown as large rounded squares, navigated entirely with the remote's D-pad.
  Only the selected app shows its name.
- Reorder and hide apps from each app's menu (press **Menu**, or hold **Select**).
- Appearance options: **Cinematic Ambient** (default), **Minimal Ambient** and **Classic**.

## Official app icon
Clean Launcher now has its official icon — a glowing cyan-to-violet home symbol on deep navy — and a
matching wide banner for the Fire TV app library.

## Cinematic Ambient design
A softly blurred dusk landscape sits behind your apps under a dark overlay that keeps icons
clear. When you move to an app, a gentle light shifts to that app's colours in under half a
second and gives the icon a soft glow. The light only moves when you do: there is no continuous
animation and no live blur. The design respects the system setting for turning animations off.

## Home-button redirection
After a one-time setup that needs a computer (see the README; installing and using the app itself
needs only the TV), pressing **Home** — or saying
**"Alexa, go home"** — takes you to Clean Launcher instead of Amazon's home screen.

Fire OS doesn't allow other apps to become the system home screen, so Clean Launcher uses an
accessibility service. It notices when Amazon's home screen opens and shows Clean Launcher in its
place. It only reacts to Amazon's actual home screen.

## Settings compatibility
- The remote's **Settings** button opens Amazon's Settings as normal and is never redirected,
  even though that screen belongs to Amazon's home app.
- Fire TV Settings and setup screens are never redirected.
- From Clean Launcher's own settings you can open **Fire TV Settings** or visit **Fire TV Home**
  whenever you like.

## Reboot and sleep/wake
- After a restart, Clean Launcher opens by itself, and the Home button works straight away.
- Waking the TV from sleep returns to Clean Launcher if that's where you were.
- **Boot-launch stability fix:** Clean Launcher now opens **at most once per
  restart**. Previously a late start-up signal from Fire OS (about 90 seconds after boot) could
  pull you out of an app you had already opened. That no longer happens.

## Turning it off
In Clean Launcher's settings: **Redirect Amazon home → Off** to pause, or **Home button redirect →
Off** to switch the feature off. To remove it completely, uninstall it from **Settings →
Applications → Manage Installed Applications**. Amazon's normal home screen is back immediately.
A built-in safety check also stops redirecting automatically if Clean Launcher ever fails to open.

## Known limitations
- **Short black transition:** pressing Home shows a black screen for about 1–1.5 seconds before
  Clean Launcher appears. This is the time Fire OS takes to start its own home screen, which
  Clean Launcher then replaces. Amazon's home screen itself is not shown.
- **One-time computer setup** is needed for the Home button feature on Fire OS 8.
- **The "Intercept Home key" option does not work on Fire OS 8.** Fire OS handles the Home button
  before apps can see it. The option is experimental and should be left off. The Home button
  feature described above doesn't depend on it.
- Holding Home still shows Amazon's quick menu, which has no Settings entry on Fire OS 8.
- After installing an update, Amazon's home may be showing until you open Clean Launcher once.
  Your settings and Home-button setup are kept.
- After an update, Amazon's Apps grid may keep showing the app's previous picture for a while (Fire OS
  caches app tiles). Fire TV Settings → Applications shows the new icon.
- Future Fire OS updates from Amazon could stop the Home button feature working.
- Only one device has been tested (see above).
